===============================================================================
       TALENTSCOUT AI — STANDALONE DESKTOP APPLICATION PACKAGE
===============================================================================

Welcome to TalentScout AI! This package is fully configured as a standalone,
zero-install desktop application for Windows 10 and Windows 11.

No command prompt, no terminal commands, and no web development tools
are needed to run this application.

-------------------------------------------------------------------------------
1. HOW TO LAUNCH THE APPLICATION
-------------------------------------------------------------------------------
Choose ANY of the following options:

Option A (Recommended):
   - Double-click the "TalentScout AI" shortcut on your Windows Desktop!

Option B:
   - Double-click "TalentScout.vbs" inside this folder.
     (This starts the app completely silently with zero black console windows).

Option C:
   - Double-click "TalentScout.bat" inside this folder.

-------------------------------------------------------------------------------
2. HOW TO SET UP THE SHORTCUT ON A NEW COMPUTER
-------------------------------------------------------------------------------
If you copy or transfer this folder to another Windows laptop or PC:
1. Open this folder on the new computer.
2. Double-click "Create_Desktop_Shortcut.bat".
3. A branded "TalentScout AI" icon will instantly appear on your Desktop!

-------------------------------------------------------------------------------
3. KEY ADVANTAGES OF THIS DESKTOP PACKAGE
-------------------------------------------------------------------------------
- 100% Native Desktop Window: Opens in a dedicated window without browser
  tabs, URL bars, or bookmark distractions.
- Zero Cloud Blocking: Searches execute through your local Wi-Fi connection,
  allowing free DuckDuckGo searches without cloud datacenter IP blocks.
- Permanent Data Storage: All candidate profiles, jobs, resumes, and notes
  are stored permanently inside the "data\talentscout.db" database on this PC.
- Automatic Clean Exit: Closing the desktop application window automatically
  terminates background services cleanly.
